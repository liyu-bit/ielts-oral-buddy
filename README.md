# IELTS Mate · 雅思口语专练（ielts-oral-buddy）

一款专注雅思口语的备考工具：随机抽题、AI 考官即兴追问、表达三档升级、全真套题计时，全部集中在一个页面里完成。

它是纯静态网页：无需安装、无需注册、也没有服务器，下载后即可使用。

> 在线版：<https://ielts-mate.app.workbuddy.host/>

## 功能一览

| 模块 | 说明 |
|---|---|
| 随机抽题 | 43 个话题、115 个题面（Part 1 共 23 话题 95 题，Part 2 共 20 张卡，Part 3 共 60 个追问）。支持按题型、场景（日常 / 学术 / 职场 / 社会）、换题季（当季新题 / 保留题）、类别、难度进行组合筛选 |
| AI 考官 | 双引擎设计。未配置 Key 时使用内置的离线规则考官，负责动态追问、跑题判定与 Part 3 抽象化；配置 Key 后切换为大模型考官，兼容 DeepSeek、通义、Kimi、智谱、OpenAI 等 OpenAI 协议服务商 |
| 三档升级 | 将你的回答改写为 Band 6 / 7 / 8 三版参考表达，并以词级 diff 高亮改动位置，附改动清单 |
| 套题模式 | 1 段 Part 1、1 张 Part 2 卡加对应 Part 3，按真实考试节奏自动推进（240s / 60s / 120s / 240s），结束后生成四维报告 |
| 复盘 | 练习历史、薄弱点本（类别覆盖与待攻克清单）、流利度统计（wpm 与填充词）、CSV 导出 |
| 生词本 | 点词收藏，支持整本朗读 |
| 口音 | 考官朗读支持英音、美音、澳音，并可调节语速 |
| 录音 | Part 2 模拟环节自动录音，供回放自查。音频保存在浏览器 IndexedDB 中，不会离开本机 |

## 快速开始

### 方式一：直接使用在线版

打开 <https://ielts-mate.app.workbuddy.host/> 即可，无需任何配置。

### 方式二：在本地运行

```bash
git clone https://github.com/liyu-bit/ielts-oral-buddy.git
```

克隆完成后，双击 `index.html` 用浏览器打开即可。如果更习惯用本地服务器，也可以这样启动：

```bash
cd ielts-oral-buddy
python -m http.server 8080
# 打开 http://localhost:8080
```

### 方式三：部署到自己的托管平台

整个项目只有几个静态文件，可以直接放到 GitHub Pages、Vercel、Netlify 或 Cloudflare Pages 中的任意一家。没有构建步骤，也不需要配置环境变量或后端服务。

## 配置 AI 考官（可选）

不配置同样可以完整使用，内置的离线考官已经可用。如果你希望得到更聪明的即兴追问和更地道的改写，可以接入大模型：

1. 任选一家 OpenAI 兼容服务商，例如 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册后创建一个 API Key（通常以 `sk-` 开头）
2. 回到首页的「AI 考官引擎」卡片，选择服务商（也可以选「自定义」并填写 Base URL）
3. 粘贴 Key，点击「保存配置」，再用「测试连接性」确认可用

> **关于隐私**：Key 仅写入你自己浏览器的 localStorage，请求由浏览器直接发送给你选定的服务商，不会经过本项目的任何服务器（本项目本身也没有服务器）。更换设备或清除浏览器数据后，需要重新填写。
>
> **关于费用**：大模型 API 按量计费。就口语练习的使用强度而言，成本通常很低，具体价格请以各服务商官网为准。

## 数据与隐私

本项目没有后端，全站只有一个网络出口，也就是你自己配置的大模型接口。没有统计、没有埋点、也不依赖第三方 CDN，任何练习数据都不会离开你的设备。

| 数据 | 存储位置 | 保存时长 |
|---|---|---|
| 练习记录 / 自评 / 生词本 / 偏好设置 | 浏览器 localStorage（`im_log`、`im_wordbook`、`im_settings`） | 直到你主动删除或清除浏览器数据 |
| 大模型 API Key（仅在你填写后存在） | 浏览器 localStorage（`im_llm`） | 同上 |
| Part 2 录音 | 浏览器 IndexedDB（`ielts-oral-buddy` → `recordings`） | 同上 |

以上数据随时可以自行删除。在复盘页的「数据与隐私」卡片中，你可以：

- 逐条删除练习记录（关联的录音会一并删除）
- 一键「删除全部录音」
- 一键「清除全部本机数据」，将记录、自评、生词本、设置、API Key 与录音一并清空

也可以直接使用浏览器的「清除站点数据」达到同样效果。练习历史与生词本还支持导出 CSV 备份。

## 项目结构

```
ielts-oral-buddy/
├── index.html   # 页面结构与样式（手写 CSS 设计系统，无框架）
├── topics.js    # 题库：window.IELTS_TOPICS（话题 / 题卡 / 词汇 / 参考表达 / 换季元信息）
├── engine.js    # 离线规则考官，以及诊断、三档改写、diff 与报告引擎
├── llm.js       # 大模型接入：OpenAI 兼容 /chat/completions 与 SSE 流式
├── app.js       # 页面逻辑：抽题、套题、录音、复盘、生词本、导出
└── 口语模块*.md  # 设计文档（迭代记录与改进建议）
```

## 换题季维护

题库集中存放在 `topics.js`。换季时增删 `part1` / `part2` 条目，并更新 `meta.version` 与 `meta.seasonRange` 即可。各页面的统计数字由自计数逻辑自动生成，不会出现漂移。

## 技术要点

- 零依赖、零构建：使用原生 HTML / CSS / JS，配合 Web Speech API（TTS 朗读与语音识别），录音基于 MediaRecorder 与 IndexedDB
- localStorage 与 IndexedDB 均做了不可用时的降级处理，隐私模式下也能正常运行
- 大模型支持流式输出（SSE），并严格解析 JSON 响应，失败时自动回退到离线引擎
- 移动端适配覆盖 ≤700px、≤560px、≤400px 三档断点，触控目标不小于 40px，输入框保持 16px 以避免 iOS 聚焦时自动缩放

## 设计系统

所有样式都集中在 `index.html` 顶部的 `:root` 令牌中。改版时只需调整令牌，不必翻找散落各处的数值。

| 类别 | 取值 |
|---|---|
| 字号 | 5 档：`28`（页标题 / 计时器）、`20`（区块标题）、`15`（卡片小标题）、`13`（正文默认）、`12`（辅助） |
| 间距 | 4px 栅格：`4 / 8 / 12 / 16 / 24 / 32 / 48`（`--sp-1…--sp-12`） |
| 圆角 | 3 档：`8`（控件）、`12`（卡片）、`999`（胶囊），另有 `4` 用于行内高亮 |
| 阴影 | 两级：L1 卡片 `--sh1`、L2 浮层 `--sh2` |
| 边框 | 中性两阶：容器 `--line`、交互控件 `--line-2` |
| 过渡 | 统一为 `.18s ease`（`--t`），并遵循 `prefers-reduced-motion` |

颜色按语义分配，一种颜色只表达一种含义：

| 颜色 | 语义 |
|---|---|
| 青绿 `--teal` | 品牌与主操作（主按钮 / 主标签 / 选中态） |
| 蓝 `--blue` | 信息（提示条 / 信息徽章 / 我的对话气泡） |
| 琥珀 `--amber` | 注意（待办 / 自动开始 / 回答过短） |
| 红 `--danger` | 破坏性操作（删除 / 跑题 / 倒计时告警） |
| 绿 `--ok` | 成功与已完成阶段 |
| 紫 `--purple` | 进阶档位（Band 8 / 已接入大模型） |

所有正文与徽章配色的对比度均经过实测，满足 **WCAG AA（≥ 4.5:1）**。界面支持键盘操作，统一使用 `:focus-visible` 焦点环；触摸与点击均有 `:active` 按下反馈。

### 图标

全站不使用 emoji。所有图标来自 `index.html` 开头定义的内联 SVG 精灵（`<defs>` 配合 `<symbol id="i-*">`，采用 24px 网格、1.75px 描边与 `currentColor`），使用时通过 `<svg class="ic"><use href="#i-dice"/></svg>` 引用。

这样做是因为原生 emoji 在不同系统上的字体、字重与基线各不相同。例如 Windows 会将英国国旗渲染成字母 “GB”，部分平台还会直接缺字；即便正常显示，按钮内的文字也难以与图标垂直对齐。SVG 则在任何设备上都完全一致，并能自动跟随字号与文字颜色。

新增图标只需在精灵中增加一个 `<symbol>`，之后在 `app.js` 里通过 `IC("图标名")` 调用，或在 HTML 中直接以 `<use>` 引用。

### 渐进披露

练习页遵循「一屏一件事」的原则，非当前动作需要的内容默认收起：

- **抽题页筛选**：五维筛选默认收起为一条状态栏，始终显示「当前筛了什么、还能抽多少题」，点击整条标题栏即可展开。筛选生效时，状态栏会变为主色并加粗。
- **备考素材**：核心词汇与可参考表达合并为一张默认收起的卡片，标题旁显示「N 词 · M 表达」，切换话题后自动重新收起。
- **对话列**：在桌面端（视口宽度 ≥961px 且高度 ≥720px）对话列使用 `position: sticky`，左侧长栏滚动时考官始终可见。

折叠状态统一由 `data-collapsed` 属性驱动（`.coll` / `.coll-head` / `.coll-body`），高度通过 `grid-template-rows: 0fr → 1fr` 过渡。不支持该过渡的浏览器会直接展开或收起，内容不会被吞掉。内部的 `<button class="coll-toggle">` 负责键盘操作与 `aria-expanded`。

### 加载与流动效

- 考官思考态是三点跳动气泡（`role="status"`，并带无障碍说明）。它只在真正需要等待时出现——本地引擎是同步的，不会为它伪造延迟
- 三档升级与练习报告生成时，使用旋转 loader 占位
- 考官提问逐字打出，并带闪烁光标，耗时约 0.3–0.6 秒，按文本长度自适应
- 以上动效在 `prefers-reduced-motion: reduce` 下会自动降级为直接整段显示
